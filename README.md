# Giza Museum Visitor System

A Software Engineering student project at Egypt University of Informatics,
Fall 2026.

The project explores how a museum can sell tickets for timed entry slots,
help visitors avoid crowded halls, and provide accessible artifact guides.
The current work covers requirements analysis and UML modeling.

## Project work

- Deliverable 1 covers the system vision, stakeholders, functional
  requirements, and activity diagrams.
- Deliverable 2 covers user stories, acceptance criteria, event analysis,
  and use case modeling. Work is in progress.
